# 7-Segment Display Interfacing using STM32

## Overview

This project demonstrates interfacing a 7-segment display with an STM32 microcontroller.

The STM32 controls the individual segments of the display using GPIO pins to display numerical values from 0 to 9.

This project helps in understanding GPIO control, digital output, and basic display interfacing using STM32.

---

## Components Used

- STM32F446RE Nucleo Board
- 7-Segment Display
- Current Limiting Resistors
- Jumper Wires
- Breadboard

---

## Features

- Displays numbers from 0 to 9
- Controls individual segments using GPIO
- Uses STM32 GPIO pins
- Demonstrates digital output control
- Can be simulated using Proteus

---

## Software Used

- STM32CubeIDE
- STM32CubeMX
- Proteus Professional
- C Programming Language
